LOUNASKIRJA / YHTEINEN TUNNUS

Yksi tunnus.
Sama keittiö, yhteiset tiedot.

Kaikki kirjautuvat käyttäjätunnuksella lounas ja yhteisellä salasanalla. Supabasen käyttäjiä tai sähköpostikirjautumista ei enää tarvita.

1 Aja päivitys Supabasessa

  1. Avaa paketin supabase/04-yhteinen-tunnus.sql Muistiossa.
  2. Kopioi KOKO sisältö Supabasen SQL Editor → New query -näkymään ja paina Run.

Tämä säilyttää nykyiset reseptit ja kirjaukset. Älä aja 01-tietokanta.sql-tiedostoa uudelleen olemassa olevaan tietokantaan. Älä poista käyttäjiä tai tauluja.

2 Päivitä tiedostot GitHubiin

  1. Avaa nykyinen lounaskirja-repositoriosi.
  2. Valitse Add file → Upload files.
  3. Vedä uuden puretun lounaskirja-kansion sisältö latausalueelle ja vahvista Commit changes. Samannimiset tiedostot korvautuvat.

Uusi kirjautuminen tarvitsee myös tiedoston src/shared-auth.mjs. Lataa koko paketti, jotta mukana tulevat kaikki tarvittavat muutokset.

3 Aseta yhteinen salasana Netlifyyn

  1. Avaa Netlifyn projektista Environment variables → Add variable.
  2. Anna nimeksi APP_PASSWORD ja arvoksi yhteinen salasana (vähintään 12 merkkiä). Voit käyttää chatissa annettua salasanaa. Valitse Functions / Production, jos scopea kysytään.
  3. Pidä aiemmat SUPABASE_URL ja SUPABASE_SECRET_KEY ennallaan.
  4. Valitse Deploys → Trigger deploy, jotta uusi koodi ja salasana tulevat käyttöön.

Salasana lisätään vain Netlifyyn. Sitä ei kirjoiteta GitHubin tiedostoihin tai tähän ohjeeseen. Vanhaa SUPABASE_PUBLISHABLE_KEY-asetusta ei enää käytetä; sen voi jättää paikalleen.

Kirjaudu sisään

Avaa sovelluksen verkkolinkki ja päivitä sivu.

Käyttäjätunnus: lounas
Salasana: Netlifyn APP_PASSWORD-kohtaan asettamasi arvo.

Kaikki tällä tunnuksella kirjautuvat voivat muokata lounaita, reseptejä, listoja ja asetuksia. Muokkauksia ei voi erotella henkilöittäin.

Jos asennat aivan alusta

Luo uusi Supabase-projekti ja aja ensin supabase/01-tietokanta.sql, sitten supabase/04-yhteinen-tunnus.sql. Tiedostoa 02-yllapitaja.sql ei tarvita.

Lataa koodit uuteen GitHub-repositorioon ja yhdistä se Netlifyyn. Asetukset: Base directory tyhjä, Build command npm run build, Publish directory public, Functions netlify/functions.

Lisää Netlifyyn SUPABASE_URL, SUPABASE_SECRET_KEY sekä APP_PASSWORD. Tarkemmat ohjeet ovat README.md-tiedostossa.

Salasanan vaihtaminen jatkossa

Muuta Netlifyn APP_PASSWORD ja julkaise uudelleen. Kaikkien pitää kirjautua tämän jälkeen uudella salasanalla. Käyttäjätunnuksen voi halutessaan vaihtaa Netlifyn APP_USERNAME-muuttujalla.
